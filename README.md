# 🍛 Babu's Food - Complete Android App

A complete, production-ready Android app for your online food business with payment integration, order tracking, and admin dashboard.

## ✨ Features

### 📱 Customer App
- Browse food items with prices
- Add items to cart
- Place orders with delivery details
- UPI payment integration (Razorpay)
- Order tracking
- No coding needed to use!

### 👨‍💼 Admin Dashboard
- Add/edit/remove food items
- View all customer orders
- Update order status (pending → delivered)
- See analytics (revenue, total orders, etc.)
- Available 24/7 from any device

### 💰 Payments
- UPI payment support (via Razorpay)
- Automatic settlement to your bank
- No payment processing fees for first year

### 🌐 Cloud Deployment
- App hosted on Google Play Store
- Backend on Railway (free tier)
- Database on cloud (PostgreSQL)
- No server management needed
